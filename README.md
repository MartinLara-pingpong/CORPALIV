
# CORPALIV - Aplicación móvil

## Descripción
Aplicación móvil desarrollada en Kotlin con Jetpack Compose para representar una solución digital relacionada con CORPALIV.

## Integrantes
- Martín Lara
- Luca Buitano

## Funcionalidades
- Navegación entre las diferentes pantallas.
- Registro e inicio de sesión.
- Consulta de información institucional y programas.
- Formulario de colaboración con validaciones visuales.
- Captura opcional de fotografías mediante la cámara.
- Almacenamiento local de solicitudes.
- Gestión del estado mediante ViewModels.
- Animaciones en la interfaz.
- Función para compartir contenido.

## Tecnologías
- Kotlin
- Jetpack Compose
- Android
- AndroidX ViewModel
- DataStore Preferences
- Git y GitHub

## Requisitos
- IntelliJ IDEA o Android Studio.
- JDK compatible con la configuración Gradle del proyecto.
- Android SDK configurado.

## Ejecución
1. Clonar el repositorio.
2. Abrir el proyecto en el IDE.
3. Esperar a que finalice la sincronización de Gradle.
4. Iniciar un emulador Android o conectar un dispositivo compatible.
5. Ejecutar la aplicación desde `MainActivity`.
